✨ STUNNING ENTRY ANIMATIONS (Use these for maximum impact!)
═══════════════════════════════════════════════════════════════

🌟 TEXT ENTRIES (Choose 1-2 per segment):
  • Write(text, run_time=1.2) - Classic typewriter effect
  • DrawBorderThenFill(text, run_time=1.5) - Professional reveal
  • FadeIn(text, shift=DOWN*0.5) - Smooth slide-in from above
  • GrowFromCenter(text) - Zoom from center point
  • SpinInFromNothing(text, angle=PI/2) - Dramatic spin entrance
  • Create(text, lag_ratio=0.1) - Letter-by-letter build

🎨 SHAPE/OBJECT ENTRIES:
  • GrowFromCenter(shape) - Expand from center
  • DrawBorderThenFill(shape, run_time=1.5) - Professional outline fill
  • FadeIn(shape, scale=0.5) - Fade in while scaling up
  • Create(shape) - Draw the shape smoothly
  • Rotate(shape, angle=TAU, run_time=1.5) - Spin while appearing

═══════════════════════════════════════════════════════════════
💥 EMPHASIS & ATTENTION (Use liberally - these make videos engaging!)
═══════════════════════════════════════════════════════════════

⚡ HIGHLIGHT EFFECTS:
  • Circumscribe(obj, color=YELLOW, buff=0.2, run_time=1.5) - Draw box around
  • Flash(obj, color=YELLOW, flash_radius=0.5, run_time=1) - Attention flash
  • Indicate(obj, scale_factor=1.3, color=YELLOW) - Pulse effect
  • Wiggle(obj, scale_value=1.2, n_wiggles=4) - Shake for emphasis
  • ApplyWave(text, direction=RIGHT, amplitude=0.3) - Wave effect

🎯 COMBINED EMPHASIS (Maximum engagement!):
  • self.play(Circumscribe(text, color=YELLOW), Flash(text))
  • self.play(Indicate(obj, color=RED), Wiggle(obj))
  • self.play(Flash(text, color=BLUE), text.animate.scale(1.2))

═══════════════════════════════════════════════════════════════
🔄 SMOOTH TRANSFORMATIONS (Professional transitions)
═══════════════════════════════════════════════════════════════

✨ MORPH & REPLACE:
  • ReplacementTransform(obj1, obj2, run_time=1.5) - Smooth morph
  • Transform(obj1, obj2) - Direct transformation
  • TransformFromCopy(obj1, obj2) - Keep original, create copy

🌊 SMOOTH MOVEMENTS:
  • self.play(obj.animate.shift(UP*2).scale(1.3), run_time=1.5, rate_func=smooth)
  • self.play(obj.animate.rotate(PI/4).set_color(BLUE), rate_func=smooth)
  • self.play(obj.animate.move_to(RIGHT*3), rate_func=there_and_back)

💫 SEQUENCED ANIMATIONS (Lag for visual interest):
  • AnimationGroup(*[Write(t) for t in texts], lag_ratio=0.2, run_time=2)
  • AnimationGroup(*[GrowFromCenter(s) for s in shapes], lag_ratio=0.15)
  • Succession(*[FadeIn(obj, shift=DOWN) for obj in group])

  • Uncreate(obj) - Reverse of Create
  • ShrinkToCenter(obj) - Shrink to nothing

═══════════════════════════════════════════════════════════════
⏱️ TIMING & PACING (Keep viewers engaged!)
═══════════════════════════════════════════════════════════════

📊 RATE FUNCTIONS (Control animation feel):
  • rate_func=smooth - Smooth ease in/out (DEFAULT - USE THIS)
  • rate_func=linear - Constant speed
  • rate_func=rush_into - Start fast, end slow
  • rate_func=rush_from - Start slow, end fast
  • rate_func=there_and_back - Go and return (wiggle)

⚡ QUICK PATTERNS:
  • Short emphasis: run_time=0.8
  • Standard animation: run_time=1.2
  • Smooth transition: run_time=1.5
  • Dramatic reveal: run_time=2.0

═══════════════════════════════════════════════════════════════
🏆 BEST PRACTICES FOR PROFESSIONAL VIDEOS
═══════════════════════════════════════════════════════════════

✅ DO:
  • Use 3-5 different animation types per segment (variety!)
  • Add emphasis animations (Circumscribe, Flash, Indicate)
  • Use smooth rate_func for professional feel
  • Apply color gradients to titles and key points
  • Sequence animations with lag_ratio for visual interest
  • Add 0.3-0.5s pauses between major animations
  • Use run_time=1.2-1.8s for smooth, not-rushed feel
  • Combine multiple animations simultaneously (self.play with multiple args)
  • Use FULL SCREEN: elements at LEFT*5, RIGHT*5, UP*3, DOWN*3
  • Create labeled concept cards for every narration concept
  • Connect related concepts with Arrow()

❌ DON'T:
  • Use only FadeIn/FadeOut (BORING!)
  • Rush animations (min run_time=1.0s)
  • Use plain white/black only (use gradients!)
  • Forget emphasis on key points
  • Skip wait times between sections
  • Use jerky movements (always use rate_func=smooth)
  • FadeOut all elements at end — KEEP THEM VISIBLE
  • Put all content in center only — SPREAD ACROSS SCREEN
  • Create unlabeled shapes — EVERY shape needs a text label

💎 PATTERN A: Labeled Concept Cards (for any noun/concept)

# Every concept in narration = a labeled RoundedRectangle
card = RoundedRectangle(corner_radius=0.2, width=4, height=2.5,

label.move_to(card.get_center())

💎 PATTERN B: Side-by-Side Comparison
```python
# For "X vs Y" or "X and Y" narration
left_box = RoundedRectangle(width=6, height=4, color=TEAL, fill_opacity=0.15)
left_box.move_to(LEFT * 4)
left_title = Text("Python", font_size=26, color=TEAL, weight=BOLD)
left_title.next_to(left_box, UP, buff=0.15)

right_box = RoundedRectangle(width=6, height=4, color=PURPLE, fill_opacity=0.15)
right_box.move_to(RIGHT * 4)
right_title = Text("JavaScript", font_size=26, color=PURPLE, weight=BOLD)

self.play(FadeIn(right_box), Write(right_title), run_time=1.5)
```

💎 PATTERN C: Process Flow with Arrows
```python
# For step-by-step narration: "first... then... finally..."
steps = []
for i, (name, col) in enumerate([("Input", BLUE), ("Process", GREEN), ("Output", GOLD)]):
    box = RoundedRectangle(width=3, height=1.5, color=col, fill_opacity=0.2)
    lbl = Text(name, font_size=24, color=WHITE, weight=BOLD)
    lbl.move_to(box.get_center())
    grp = VGroup(box, lbl)
    grp.move_to(LEFT * 5 + RIGHT * 5 * i + DOWN * 0.5)
    steps.append(grp)

for j, step in enumerate(steps):
    self.play(GrowFromCenter(step), run_time=1.5)
    if j < len(steps) - 1:
        arrow = Arrow(step.get_right(), steps[j+1].get_left(), color=YELLOW)
        self.play(GrowArrow(arrow), run_time=0.8)
```

💎 PATTERN D: Hierarchical Layout (Tree/Org Chart)
```python
# Parent concept at top, children below
parent = VGroup(RoundedRectangle(width=4, height=1.5, color=GOLD, fill_opacity=0.2),
                Text("Machine Learning", font_size=24, color=WHITE, weight=BOLD))
parent[1].move_to(parent[0].get_center())
parent.move_to(UP * 2.5)

children_data = [("Supervised", LEFT*4), ("Unsupervised", ORIGIN), ("Reinforcement", RIGHT*4)]
children = []
for name, pos in children_data:
    child = VGroup(RoundedRectangle(width=3.5, height=1.2, color=BLUE, fill_opacity=0.2),
                   Text(name, font_size=20, color=WHITE))
    child[1].move_to(child[0].get_center())
    child.move_to(pos + DOWN * 0.5)
    children.append(child)

self.play(GrowFromCenter(parent), run_time=1.5)
for child in children:
    arrow = Arrow(parent.get_bottom(), child.get_top(), color=WHITE, stroke_width=2)
    self.play(GrowArrow(arrow), GrowFromCenter(child), run_time=1.2)
```

📐 POSITIONING RULES (MANDATORY — Use Full Screen!)
═══════════════════════════════════════════════════════════════

  • Left: LEFT * 4
  • Center-left: LEFT * 2
  • Center: ORIGIN
  • Center-right: RIGHT * 2
  • Right: RIGHT * 4
  • Far right: RIGHT * 5.5 to RIGHT * 6

VERTICAL:
  • Top: UP * 3 to UP * 3.5
  • Upper: UP * 1.5
  • Center: ORIGIN
  • Lower: DOWN * 1.5
  • Bottom: DOWN * 3 to DOWN * 3.5

RULE: At least 2 different horizontal zones and 2 vertical zones per segment.
