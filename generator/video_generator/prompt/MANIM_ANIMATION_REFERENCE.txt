1. ENTRY/CREATION ANIMATIONS
================================================================================

Basic Entries:
--------------
FadeIn(object, shift=UP, run_time=1)
    - Object fades in gradually
    - Optional shift direction: UP, DOWN, LEFT, RIGHT
    - Example: self.play(FadeIn(title, shift=UP))

Create(object, run_time=1, lag_ratio=0.1)
    - Draws the object smoothly from start to finish
    - Works great for shapes and paths
    - Example: self.play(Create(circle))

GrowFromCenter(object, run_time=1)
    - Object grows outward from center point
    - Very dynamic and attention-grabbing
    - Example: self.play(GrowFromCenter(square))

GrowFromEdge(object, edge=UP, run_time=1)
    - Grows from specific edge (UP, DOWN, LEFT, RIGHT)
    - Good for directional reveals
    - Example: self.play(GrowFromEdge(rect, edge=LEFT))

GrowFromPoint(object, point, run_time=1)
    - Grows from a specific coordinate
    - Example: self.play(GrowFromPoint(circle, ORIGIN))

Advanced Entries:
-----------------
DrawBorderThenFill(object, run_time=2, stroke_width=2)
    - First draws outline, then fills interior
    - Very professional looking
    - Example: self.play(DrawBorderThenFill(polygon))

SpinInFromNothing(object, angle=PI, run_time=1)
    - Spins in while growing
    - Highly dynamic entrance
    - Example: self.play(SpinInFromNothing(star, angle=2*PI))

Write(text_object, run_time=2, lag_ratio=0.05)
    - Text appears as if being typed/written
    - Perfect for emphasis and readability
    - Example: self.play(Write(title, run_time=1.5))

AddTextLetterByLetter(text_object, run_time=2)
    - Letters appear one by one
    - Slower, more deliberate than Write
    - Example: self.play(AddTextLetterByLetter(caption))

ShowIncreasingSubsets(group, run_time=2)
    - Items in VGroup appear sequentially
    - Example: self.play(ShowIncreasingSubsets(items))

ShowSubmobjectsOneByOne(group, run_time=2)
    - Sub-objects appear one at a time
    - Example: self.play(ShowSubmobjectsOneByOne(text))

2. EXIT/REMOVAL ANIMATIONS
================================================================================

Basic Exits:
------------
FadeOut(object, shift=DOWN, run_time=1)
    - Object fades away
    - Optional shift direction
    - Example: self.play(FadeOut(text, shift=DOWN))

Uncreate(object, run_time=1, reverse_rate_function=False)
    - Reverses the creation process
    - Very satisfying to watch
    - Example: self.play(Uncreate(circle))

ShrinkToCenter(object, run_time=1)
    - Object shrinks to its center and disappears
    - Clean, focused exit
    - Example: self.play(ShrinkToCenter(square))

Advanced Exits:
---------------
FadeToColor(object, color=BLACK, run_time=1)
    - Transitions to a color before disappearing
    - Example: self.play(FadeToColor(text, color=BLACK))

ScaleInPlace(object, scale_factor=0, run_time=1)
    - Scales down to nothing
    - Example: self.play(ScaleInPlace(obj, scale_factor=0))

3. MOVEMENT & TRANSFORMATION
================================================================================

Position Changes:
-----------------
object.animate.shift(direction*distance)
    - Moves object in direction
    - Directions: UP, DOWN, LEFT, RIGHT, or combinations
    - Example: self.play(title.animate.shift(UP*2 + RIGHT*1))

object.animate.move_to(position)
    - Moves to specific position
    - Positions: ORIGIN, UP*2, LEFT*3, etc.
    - Example: self.play(circle.animate.move_to(RIGHT*3))

object.animate.next_to(other_object, direction, buff=0.5)
    - Positions relative to another object
    - Example: self.play(text.animate.next_to(title, DOWN, buff=0.3))

object.animate.to_edge(edge, buff=0.5)
    - Moves to screen edge
    - Edges: UP, DOWN, LEFT, RIGHT, UL, UR, DL, DR
    - Example: self.play(logo.animate.to_edge(UL, buff=0.3))

object.animate.to_corner(corner, buff=0.5)
    - Moves to corner
    - Corners: UL, UR, DL, DR
    - Example: self.play(watermark.animate.to_corner(DR))

Scale & Rotate:
---------------
object.animate.scale(factor)
    - Resizes object
    - factor > 1: enlarges, factor < 1: shrinks
    - Example: self.play(text.animate.scale(1.5))

object.animate.rotate(angle, about_point=ORIGIN)
    - Rotates object
    - Angle in radians (PI = 180°)
    - Example: self.play(square.animate.rotate(PI/4))

object.animate.flip(axis=RIGHT)
    - Flips object along axis
    - Example: self.play(text.animate.flip())

Transformations:
----------------
Transform(object1, object2, run_time=1)
    - Morphs object1 into object2
    - Object1 is replaced
    - Example: self.play(Transform(circle, square))

ReplacementTransform(object1, object2, run_time=1)
    - Transforms and replaces object1 with object2
    - Cleaner than Transform for most cases
    - Example: self.play(ReplacementTransform(old_text, new_text))

TransformFromCopy(object1, object2, run_time=1)
    - Creates object2 as a transformation of object1
    - Original object1 remains
    - Example: self.play(TransformFromCopy(formula1, formula2))

ClockwiseTransform(object1, object2)
    - Transform with clockwise rotation
    - Example: self.play(ClockwiseTransform(shape1, shape2))

CounterclockwiseTransform(object1, object2)
    - Transform with counter-clockwise rotation
    - Example: self.play(CounterclockwiseTransform(shape1, shape2))

MoveToTarget(object)
    - Moves object to its assigned target
    - Must set object.generate_target() first
    - Example:
        circle.generate_target()
        circle.target.shift(RIGHT*3)
        self.play(MoveToTarget(circle))

4. EMPHASIS & ATTENTION
================================================================================

Highlight Effects:
------------------
Indicate(object, color=YELLOW, scale_factor=1.2, run_time=1)
    - Brief scaling pulse to draw attention
    - Perfect for highlighting key points
    - Example: self.play(Indicate(important_text, color=YELLOW))

Flash(object, color=YELLOW, line_length=0.3, num_lines=12, run_time=0.5)
    - Radiating flash effect
    - Great for "aha!" moments
    - Example: self.play(Flash(solution, color=RED))

FocusOn(object, color=GRAY, opacity=0.8, run_time=1)
    - Dims everything except the focused object
    - Creates spotlight effect
    - Example: self.play(FocusOn(key_formula))

Circumscribe(object, color=YELLOW, fade_in=True, fade_out=True, run_time=1, 
             shape=Circle, buff=0.1)
    - Draws shape around object
    - Shapes: Circle, Rectangle, Ellipse
    - Example: self.play(Circumscribe(answer, color=GREEN))

ShowPassingFlash(object, time_width=0.1, run_time=1)
    - Moving highlight along path
    - Example: self.play(ShowPassingFlash(line))

ShowCreationThenFadeAround(object, surrounding_shape=Circle, run_time=2)
    - Creates then fades surrounding shape
    - Example: self.play(ShowCreationThenFadeAround(text))

Movement for Emphasis:
----------------------
Wiggle(object, scale_value=1.1, rotation_angle=0.01*TAU, run_time=1)
    - Subtle shake to draw attention
    - Example: self.play(Wiggle(warning_text))

ApplyWave(object, direction=UP, amplitude=0.1, run_time=1)
    - Wave distortion effect
    - Example: self.play(ApplyWave(text, direction=UP))

7. ADVANCED TECHNIQUES
================================================================================

Animation Groups:
-----------------
AnimationGroup(*animations, lag_ratio=0, run_time=1)
    - Plays multiple animations together
    - lag_ratio: 0 = simultaneous, 1 = sequential
    - Example:
        self.play(
            AnimationGroup(
                FadeIn(obj1),
                FadeIn(obj2),
                FadeIn(obj3),
                lag_ratio=0.2
            )
        )

Succession(*animations)
    - Plays animations one after another
    - Example: Succession(FadeIn(a), FadeIn(b), FadeIn(c))

LaggedStart(*animations, lag_ratio=0.1)
    - Staggered start for animations
    - Example: self.play(LaggedStart(Create(l1), Create(l2), Create(l3)))

Rate Functions:
---------------
rate_func=smooth
    - Ease in and out (default)

rate_func=linear
    - Constant speed

rate_func=rush_into
    - Starts slow, accelerates

rate_func=rush_from
    - Starts fast, decelerates

rate_func=there_and_back
    - Goes forward then backward

rate_func=wiggle
    - Oscillating motion

Example:
    self.play(circle.animate.shift(RIGHT*3), run_time=2, rate_func=smooth)

Custom Animation Curves:
-------------------------
def custom_rate(t):
    return t**2  # Quadratic acceleration

self.play(obj.animate.shift(UP*2), rate_func=custom_rate)

Path Following:
---------------
MoveAlongPath(object, path, run_time=2)
    - Object follows a path/curve
    - Example:
        path = ArcBetweenPoints(LEFT*3, RIGHT*3)
        self.play(MoveAlongPath(dot, path))

Rotate(object, angle, about_point=ORIGIN, run_time=1)
    - Continuous rotation animation
    - Example: self.play(Rotate(shape, angle=2*PI))

Updaters:
---------
object.add_updater(lambda m, dt: m.rotate(dt))
    - Continuous update based on time
    - Example: 
        def rotate_updater(mob, dt):
            mob.rotate(PI*dt)
        circle.add_updater(rotate_updater)

8. TIMING & COORDINATION
================================================================================

Perfect Timing Pattern:
-----------------------
def construct(self):
    audio_duration = 10.5  # seconds
    total_time = 0
    
    # Track time for each animation
    self.play(Write(title, run_time=1.5))
    total_time += 1.5
    
    self.play(title.animate.shift(UP*2), run_time=0.8)
    total_time += 0.8
    
    self.play(Create(diagram, run_time=2.0))
    total_time += 2.0
    
    # ... more animations
    
    # Final wait to match exact duration
    self.wait(audio_duration - total_time)

Parallel Animations:
--------------------
# Multiple objects at once
self.play(
    FadeIn(obj1),
    FadeIn(obj2),
    obj3.animate.shift(UP)
)

# Sequential with lag
self.play(
    LaggedStart(
        Write(line1),
        Write(line2),
        Write(line3),
        lag_ratio=0.3
    )
)

Wait Commands:
--------------
self.wait(2)  # Wait 2 seconds
self.wait()   # Wait 1 second (default)
self.wait_until(condition)  # Wait for condition

9. LAYOUT & POSITIONING
================================================================================

Absolute Positioning:
---------------------
ORIGIN  # Center (0, 0, 0)
UP      # (0, 1, 0)
DOWN    # (0, -1, 0)
LEFT    # (-1, 0, 0)
RIGHT   # (1, 0, 0)

# Combinations
UP*2 + RIGHT*3  # (3, 2, 0)

Relative Positioning:
---------------------
text.next_to(title, DOWN, buff=0.5)
    - Positions below title with buffer
    
text.next_to(title, RIGHT, aligned_edge=UP, buff=0.3)
    - Positions to right, aligned at top

obj.align_to(other_obj, UP)
    - Aligns top edges

obj.align_to(other_obj, LEFT)
    - Aligns left edges

Edge Positioning:
-----------------
obj.to_edge(UP, buff=0.5)
    - Moves to top edge with buffer

obj.to_corner(UR, buff=0.3)
    - Moves to upper-right corner

obj.move_to(ORIGIN)
    - Centers object

Group Arrangements:
-------------------
VGroup(obj1, obj2, obj3).arrange(DOWN, buff=0.3)
    - Vertical arrangement with spacing

VGroup(obj1, obj2, obj3).arrange(RIGHT, buff=0.5)
    - Horizontal arrangement

group.arrange_in_grid(rows=2, cols=3, buff=0.4)
    - Grid layout

Center & Scale to Fit:
----------------------
obj.scale_to_fit_width(5)
    - Scales to specific width

obj.scale_to_fit_height(3)
    - Scales to specific height

obj.center()
    - Moves to center

11. PROFESSIONAL PATTERNS & TEMPLATES

Template 1: Title + Content
----------------------------
def construct(self):
    # Title entry
    title = Text("Main Topic", font_size=56)
    self.play(Write(title, run_time=1.5))
    self.play(title.animate.to_edge(UP, buff=0.5), run_time=0.8)
    
    # Content appears
    content = VGroup(
        Text("Point 1", font_size=36),
        Text("Point 2", font_size=36),
        Text("Point 3", font_size=36)
    ).arrange(DOWN, aligned_edge=LEFT, buff=0.4)
    content.next_to(title, DOWN, buff=1)
    
    self.play(
        LaggedStart(
            *[GrowFromCenter(item) for item in content],
            lag_ratio=0.3
        )
    )
    
    # Emphasize each
    for item in content:
        self.play(Indicate(item, color=YELLOW), run_time=0.6)
    
    # Exit
    self.play(
        ShrinkToCenter(title),
        *[FadeOut(item, shift=DOWN) for item in content]
    )

Template 2: Comparison (Side-by-Side)

def construct(self):
    # Title
    title = Text("Comparison", font_size=48)
    title.to_edge(UP)
    self.play(Write(title))
    
    # Left side
    left_title = Text("Option A", font_size=36, color=BLUE)
    left_content = VGroup(
        Text("Feature 1"),
        Text("Feature 2"),
        Text("Feature 3")
    ).arrange(DOWN, buff=0.2)
    left_group = VGroup(left_title, left_content).arrange(DOWN, buff=0.5)
    left_group.to_edge(LEFT, buff=1)
    
    # Right side
    right_title = Text("Option B", font_size=36, color=GREEN)
    right_content = VGroup(
        Text("Feature 1"),
        Text("Feature 2"),
        Text("Feature 3")
    ).arrange(DOWN, buff=0.2)
    right_group = VGroup(right_title, right_content).arrange(DOWN, buff=0.5)
    right_group.to_edge(RIGHT, buff=1)
    
    # Animate both sides
    self.play(
        GrowFromCenter(left_group),
        GrowFromCenter(right_group),
        lag_ratio=0.2
    )

Template 3: Process Flow
-------------------------
def construct(self):
    # Steps in sequence
    steps = VGroup(
        Text("Step 1: Research"),
        Text("Step 2: Design"),
        Text("Step 3: Build"),
        Text("Step 4: Test")
    ).arrange(DOWN, aligned_edge=LEFT, buff=0.5)
    steps.move_to(ORIGIN)
    
    # Add arrows between steps
    arrows = VGroup(*[
        Arrow(steps[i].get_bottom(), steps[i+1].get_top(), buff=0.1)
        for i in range(len(steps)-1)
    ])
    
    # Animate steps appearing
    for i, step in enumerate(steps):
        self.play(Write(step, run_time=1))
        if i < len(arrows):
            self.play(GrowArrow(arrows[i]), run_time=0.5)
        self.play(Circumscribe(step, color=YELLOW), run_time=0.8)

def construct(self):
    # Start state
    start = Circle(radius=1, color=BLUE)

    self.wait(0.5)
    
    # Transform 2
    end = Star(color=YELLOW)
    end_label = Text("Complete", font_size=24).next_to(end, DOWN)
    
    self.play(
        Transform(start, end),
        TransformMatchingShapes(start_label, end_label),
        run_time=1.5
    )
    self.wait(0.5)

12. PERFORMANCE TIPS
================================================================================

1. Use VGroup for Related Objects:
   items = VGroup(obj1, obj2, obj3)
   self.play(*[Create(item) for item in items])

2. Reduce Complexity:
   - Use fewer vertices for shapes
   - Simplify paths and curves
   - Reduce resolution for testing

3. Efficient Animations:
   - Combine multiple animations in one self.play()
   - Use lag_ratio instead of sequential plays
   - Remove objects when no longer needed

4. Memory Management:
   self.remove(old_object)  # Free up memory
   self.clear()  # Remove all objects

5. Caching:
   - Manim caches by default
   - Use --disable_caching to force regeneration
   - Clear cache when making significant changes
